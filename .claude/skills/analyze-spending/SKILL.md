# Анализ трат

## Данные

- Выгрузки: `exports/traty_<от>_<до>.csv`. Колонки: `date, weekday, amount, currency, amount_vnd, amount_rub, amount_usd, category, note, recurring`.
- Считай в рублях (`amount_rub`) — пользователь думает в рублях. Донги указывай рядом, если это помогает.
- `recurring=yes` — регулярные платежи (аренда, подписки). Анализируй их отдельно от повседневных трат: их сокращают другими решениями.
- Прошлые отчёты: `exports/analyses/*.md`. Прочитай последние 2–3, чтобы сравнивать с ними и проверить, сработали ли прошлые рекомендации.

Если пользователь не указал файл — возьми самый свежий CSV в `exports/`. Посчитай всё скриптом (python3, только стандартная библиотека), не на глаз.

## Что посчитать

1. Итог за период, в среднем в день, проекция на месяц (среднее в день × 30).
2. Разбивка по категориям: сумма, доля, число трат, средний чек.
3. Сравнение с прошлой выгрузкой (или прошлым отчётом): изменение по категориям в % и в рублях. Нормируй на число дней, если периоды разной длины.
4. Повседневные траты отдельно от регулярных.
5. Дни недели: где пики (например, выходные).
6. Аномалии: крупные разовые траты (больше 3× медианы своей категории), всплески, частые мелкие траты (кофе, Grab), которые в сумме заметны.
7. Комментарии (`note`): повторяющиеся места и сервисы.

## Формат отчёта

Коротко и по делу, на русском:

1. **Итог** — 2–3 предложения: сколько потрачено, куда ушло больше всего, как это относится к прошлому периоду.
2. **Таблица по категориям** (₽, доля, Δ к прошлому периоду).
3. **Что заметно** — 3–5 наблюдений с цифрами.
4. **Где можно сократить** — 2–4 конкретные идеи с оценкой экономии в ₽ в месяц. Без общих советов вроде «тратьте меньше».
5. **Как прошли прошлые рекомендации** — если есть прошлый отчёт.

Сохрани отчёт в `exports/analyses/<до>.md` (дата конца периода), чтобы следующий анализ мог на него опереться.

Не давай инвестиционных советов. Речь только о структуре личных расходов.
