# Траты — личный учёт расходов

PWA без сборки и зависимостей: `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icons/`.
Данные живут только на устройстве (IndexedDB `trati`: `tx`, `cats`, `rec`, `kv`). Сервера нет.

- Локальный запуск: `python3 -m http.server 8787` (или конфигурация `trati` в `.claude/launch.json`). На localhost service worker отключён.
- После изменения файлов поднимать `VERSION` в `sw.js`, иначе телефон продолжит показывать старую версию из кэша.
- Валюты: VND (основная), RUB, USD. Курс берётся из бесплатного fawazahmed0/currency-api, хранится как «единиц за 1 USD». Каждая трата сохраняет курс на момент ввода (`fx`), если он свежий.
- Цвета категорий — 8 фиксированных слотов (`--s0..--s7`), в диаграмме максимум 7 категорий + «Другое».

## Анализ трат

Выгрузки (CSV из приложения) лежат в `exports/`, отчёты — в `exports/analyses/`.
Для анализа использовать скилл `/analyze-spending`.
