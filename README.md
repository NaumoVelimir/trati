# Траты

Личный учёт расходов: PWA, работает без интернета, данные только на телефоне.

## Как поставить на телефон

1. Опубликовать папку на любом HTTPS-хостинге (например, GitHub Pages).
2. Открыть ссылку в Safari (iPhone) или Chrome (Android).
3. «Поделиться» → «На экран „Домой“».

## Раз в две недели

1. «Ещё» → «Последние 14 дней» → отправить файл на Mac (AirDrop/Telegram).
2. Положить CSV в `exports/`.
3. В Claude Code в этой папке: `/analyze-spending`.

## Резервная копия

«Ещё» → «Сохранить резервную копию». Хранится JSON со всем: траты, категории, регулярные платежи, настройки.
